# USKORUN

**USKORUN** — исследовательский проект: клубные беговые челленджи и партнёрские награды для рынка США.

**Статус (2026-10-15):** R&D / pre-MVP. Вся рыночная оценка — гипотезы до выхода и проверки полного Deep Research. Код продукта не реализован.

## Что строим

Веб-приложение, в котором участник выбирает беговой челлендж, подтверждает выполнение допустимым способом, получает ограниченную награду от локального партнёра и может вступать в беговые клубы. Со временем — интеграции с разрешёнными источниками активности.

## Важные ограничения

1. **Нельзя напрямую прочитать Apple Health из сайта/PWA:** HealthKit — нативная iOS/watchOS-возможность.
2. **Нельзя предполагать, что Strava разрешает rewards/virtual challenges:** условия API требуют отдельной проверки и, вероятно, согласования.
3. Не передавать партнёрам сырые GPS-треки, историю здоровья или данные из HealthKit. Для погашения награды использовать одноразовый токен без деталей тренировки.
4. Репозиторий **сейчас публичный**: никаких ключей, клиентских персональных данных или коммерческих договоров здесь хранить нельзя.

## Следующие R&D-ворота

- Интервью 20–30 бегунов / 10–15 магазинов и 3–5 клубов.
- Проверка юридических правил для health data, скидок/донатов и платных конкурсов в США.
- Первые 2–3 локальных челленджа и тест выдачи/погашения купонов.
- Подтверждение экономики и повторного участия.
