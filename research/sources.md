# Source Registry — USKORUN
_Compiled 2026-10-15. This is a curated starter registry, not the comprehensive Deep Research bibliography._

## Platform / legal primary sources
1. Apple — [Configuring HealthKit access](https://developer.apple.com/documentation/Xcode/configuring-healthkit-access). HealthKit capability and native app targeting.
2. Apple — [Authorizing access to health data](https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data). Permission scopes and limits.
3. Apple — [Protecting user privacy](https://developer.apple.com/documentation/HealthKit/protecting-user-privacy). Purpose and third-party data restrictions.
4. Apple — [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/), section 5.1.3. Data and benefits for users; caution on marketing/benefit provider.
5. Strava — [Developers](https://developers.strava.com/). API warning regarding virtual races and competitive products.
6. Strava — [Getting Started](https://developers.strava.com/docs/getting-started/). OAuth, scopes overview, limits, review and webhooks.
7. Strava — [Rate Limits](https://developers.strava.com/docs/rate-limits/). Limits and application review.
8. Strava — [API Agreement](https://www.strava.com/legal/api). Required contract, review latest directly.
9. Strava — [Brand Guidelines](https://developers.strava.com/guidelines/). Required attribution and trademark rules.
